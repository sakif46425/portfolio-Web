Comparative Study of Machine Learning Models for Earthquake Magnitude Prediction

Type: Thesis / Machine Learning Research Project Role: Researcher & Machine Learning Developer

Developed a comparative machine learning framework for predicting earthquake magnitude from seismic records. The project evaluated six regression models — Linear Regression, Support Vector Regression, K-Nearest Neighbors, Decision Tree, Random Forest, and XGBoost — using MAE, RMSE, and R² evaluation metrics, with data preprocessing, feature standardization, an 80:20 train-test split, multi-model training, performance comparison, feature importance analysis, and magnitude-class visualization.

XGBoost led the field — R² 0.9262, MAE 0.1574, RMSE 0.2242
  • Comparative analysis of six machine learning regression models
  • Automated data preprocessing and feature scaling
  • Model evaluation using MAE, RMSE, and R² Score
  • XGBoost-based feature importance analysis
  • Actual vs. predicted earthquake magnitude visualization
  • Magnitude classification using confusion matrix analysis

Research Outcome: the study showed ensemble and boosting-based models — particularly XGBoost — are highly effective for modeling nonlinear relationships in seismic data.
